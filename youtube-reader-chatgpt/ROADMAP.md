# Roadmap

## V1 acceptance
- One read-only MCP tool.
- Public captions retrieval.
- QA metadata and duplicate detection.
- No secrets and no storage.
- Free hosting target.

## V2 only after evidence
- Direct caption extractor as primary with upstream MCP as fallback, if cloud reliability is acceptable.
- Speech-to-text fallback for genuinely captionless public videos, only if usage volume justifies cost/complexity.
- Visual-frame extraction for `/read deep` when transcript references charts/slides.

Stop adding architecture when V1 achieves reliable one-link `/read` with low owner effort.
